# 字母信使：两次运行的通信题示例

选手提交一个程序。每个测试点上，平台先运行它一次，再清空运行环境并运行同一个程序第二次。两次运行之间只能通过裁判认可的消息传递信息。

## 题目描述

第一次运行会收到一个长度为 `n` 的整数数组，满足 `1 <= n <= 10000`、`1 <= a[i] <= 26`。你需要把数组编码成一个只包含 `a` 到 `z` 的非空字符串，长度不超过 100000。输出编码后，程序应正常结束。

第二次运行只能获得该编码字符串，必须还原原数组长度及所有元素。两轮进程的变量和文件不会保留。每轮独立使用题目规定的时间和内存限制。

第一次运行的输入格式：

```text
first
n
a[1] a[2] ... a[n]
```

第一次运行输出一行编码字符串。裁判检查字符集和长度后，生成第二次运行的输入：

```text
second
编码字符串
```

第二次运行输出 `n`，随后输出原数组的 `n` 个整数，以空白字符分隔。输出中不能有额外内容。

例如，使用 `1 → a`、`2 → b` 的编码规则时：

| 阶段 | 输入 | 输出 |
| --- | --- | --- |
| 第一次运行 | `first`，`5`，`1 2 3 4 5` | `abcde` |
| 第二次运行 | `second`，`abcde` | `5 1 2 3 4 5` |

这两行描述同一个测试点的完整执行过程。程序不在一轮内等待评测器回答，不需要为每条消息额外刷新 stdout；正常退出会刷新缓冲区。

## 导入 NovaJudge

1. 新建题目并选择「通信题」，建议时间限制 1000 ms、内存限制 256 MB。
2. 把 `problem.yml`、`communicator.cpp`、`1.in`、`2.in` 放在同一个 ZIP 的根目录，上传到测试数据。
3. 提交 `solution.cpp`，两个测试点均应 AC；提交 `wrong.cpp`，第二轮检查应得到 WA。

测试数据中的 `.in` 是第一轮完整输入，包含 `first`。本例根据原始输入验证第二轮答案，不需要标准答案文件，因此 `output` 使用 `/dev/null`。

配置里的 `communication.output_limit` 是每轮选手输出的字节限制。该限制和本题的「仅小写字母、最多 100000 个字符」是两项不同约束；后者由 `communicator.cpp` 在 `prepare` 阶段检查。

## 填写两轮样例

题目编辑器中，一个通信题样例包含同一个测试点的两轮输入和输出。添加一个样例，按下面四个字段填写；不要把第二轮另加成一个样例。

第一轮输入：

```text
first
5
1 2 3 4 5
```

第一轮输出：

```text
abcde
```

第二轮输入：

```text
second
abcde
```

第二轮输出：

```text
5
1 2 3 4 5
```

另外的「裁判参考答案」留空即可：本例裁判不读取参考答案。这个字段仅供管理员和裁判使用，不会在公开题面展示。

`first` 和 `second` 是程序实际读入的阶段标识。平台不会自动给第一轮输入补上 `first`；实际第二轮输入中的 `second` 由本例裁判写出。

以上四个字段在题面展示一种合法的通信过程。管理员调试样例时，平台只把填写的第一轮输入作为初始输入，再根据选手**真实的第一轮输出**生成第二轮输入。不会直接使用展示用的 `second\nabcde`，也不会把 `abcde` 当作唯一正确的编码答案。调试结果可查看真实的第一轮输出、第二轮输入和最终输出。

[samples.json](samples.json) 提供上述样例的数据结构。其中 `input` 是第一轮输入，`communication` 保存另外三个公开字段，`output` 是独立的私有裁判参考答案。此文件用于说明和复制参考，不会随测试数据 ZIP 自动导入样例，请在题目编辑器填写。

已有通信题样例保持原来的第一轮输入和裁判参考答案；新增的三个展示字段初始为空，可在编辑器补齐，无需迁移旧数据。

## 裁判程序

`communicator.cpp` 使用平台提供的 `testlib.h`：

- `prepare`：验证第一轮输出，并把 `second` 和编码字符串写到 stdout。
- `check`：比较第二轮还原出的数组与原始输入。

本例不需要 `state.txt`。它也不会把原始数组写进第二轮输入。所有源码均为本项目示例实现；通信题概念可参照 [Codeforces 2168A1](https://codeforces.com/problemset/problem/2168/A1)。

完整接口、限制与兼容性说明见 [通信题文档](../../../docs/COMMUNICATION_PROBLEMS.md)。
